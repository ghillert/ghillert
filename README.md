# Aloha, I’m Gunnar Hillert 🤙

**Software engineer · Java Champion · Open-source contributor · DevNexus co-founder**

I’m the founder of [Hillert, Inc.](https://hillert.com/), based on
Hawaiʻi Island. My work centers on Java and Spring, drawing on a
background in enterprise integration and distributed systems.

Open source has been part of my professional work since 2011.
I enjoy building full-stack applications, contributing to open-source
projects and sharing knowledge with fellow developers.

## What I’m building

I’m building [Pembana](https://pembana.com/): software for botanical
gardens, arboreta and plant collectors, alongside reusable open-source
libraries and tools.

Selected projects:

- **[Pembana Search](https://github.com/pembana/pembana-search)** —
  Advanced search expressions for Spring Data JPA, with optional
  Spring Boot and Spring MVC integration. Currently in development.
- **[Pembana Image Filters](https://github.com/pembana/pembana-image-filters)** —
  Java image-processing filters based on Jerry Huxtable’s JHLabs filters.
- **[Pembana Rain Gauge](https://github.com/pembana/pembana-rain-gauge)** —
  Tools for exploring rainfall observations from Hawaiʻi monitoring stations.
